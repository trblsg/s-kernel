# Rev9 autonomous thermal profile (S9 starlte)
Opt in with the paired installer and p1279=1 on top of the complete Rev8.1 prerequisites. ABI: 6/7/81/9. No manual pilot sequence, no required target temperature, and no host policy writes. Use the phone normally. This is a candidate, not a measured thermal or FPS improvement.

## Functional changes
G2 keeps the native binding record for other texture units across a known forwarded bind. Raw/unknown binds, deletes, context changes and verification failures invalidate conservatively; first candidate per binding and periodic checks validate the active unit and actual binding. IOSurface freshness and seed checks remain. Hash4 defaults to mode 2, independently of G2 and profiler. All bytes including tails are covered, scalar uses the identical digest, and sampled mismatch disables fast hash and forces refresh. Migration forces refresh. No seed-only shortcut. Import rejection records count/bytes/wall by share/mirror reason and backend error. Upload lock/convert/TexImage timing is separate. No forced zero-copy or changed texture format. Existing display flush/fence/wait semantics retained. Metal layout only gets sparse diagnostic output, no new layout implementation.
CPU boost 150 ms, burst 60 ms and Rev8.1 policy-2 lower-only tail are retained. IRQ probation observes 1024 interrupt completions, retires on >10% late after 128 observed completions, existing 64 consecutive misses, arm failure or timeout; counters are not proof of sustained power saving. Auto Idle uses the existing staged same-boot rail/UFS/ABOX qualification and lease rollback, admitted once, no automatic rearm on manual disable. No new bus, voltage, PSCI, or hardware sleep controls.
Panel remains opt-in. Optional BTA 0A/0E reads removed from Rev9 DCS transition; DPU/FIFO/PHY drain must still pass; log submask on failure. Existing panel command, DSC/PPS and frame sequencing preserved. Actual panel behavior is unverified.

## Evidence
- p1279-gl: context 5-second wall/CPU paired samples, zero-refill hash bytes/time, attach, actual hash counts. Render CPU sampled 1/16 using Mach thread CPU time, not GPU wait inferred from wall minus CPU. p1279-resumed-gl marks first completed frame after >500 ms render gap (not proof of display wake).
- p1279-import, p1279-backend, p1279-upload: reason counts and byte totals, actual GL error where available; backend internal stride/MMU cause not inferred. Shared reason 0 success,1 disabled,2 invert,3 alpha,4 format,5 plane,6 dimensions,7 backend; mirror 8 disabled,9 not target,10 backend,11 success. Backend 1 disabled,2 lookup,3 layout,4 lock,5 base,6 backend,7 pending error queue,8 native GL error bucket.
- Existing p123 G2/GL path and p0 hash logs remain. Compare matched workloads, not a single frame or an arbitrary mixed window.
- p1279-thermal: existing guard cadence 200 ms, summaries 5 s ON/30 s OFF. Eight cached sensors carry timestamp and coherence flag; stale/invalid entries are not new readings. Ring 128 rolling entries, pre25/post50, latest completed wake or fast-rise event; capture in progress temporarily invalidates previous frozen pages. Read p1279_wake0..24 after capture complete; each page carries event/page/rows/total. Row fields: seq,ticks,on,big_mc,little_mc,gpu_mc,battery,age,slope,mask,big_khz,little_khz,big_measured_mhz,little_measured_mhz,big_load_sum,little_load_sum,big_cap,little_cap,tmu_ticks,tmu_coherent,big1,big2,big3,big4,big6,little5,g3d1,isp2. No extra TMU MMIO or gauge polling. Existing gauge logs continue. Ring is volatile, not a crash-persistent flight recorder.
- Read-only sysctls p1279_revision, p1279_irq_state, p1278_irq_stats, p1278_active_stats, p1277_auto_stats. IRQ states 0 manual/off,1 probation,2 observed,3 retired.
- Independent manual kill switches (not required for normal use): kern.hakios.mali_irq=0, kern.hakios.p1277_active=0, kern.hakios.p1277_g2=0, kern.hakios.p1279_hash_mode=0, kern.hakios.p1277_auto_idle=0. Use only if troubleshooting; no scripted pilot.

## Validation
Host C fixtures and source contracts are not a full XNU/iOS SDK compilation or hardware validation. Paired installer must pass native build/link and exact source lock before flashing. Do not promise 12–14 ms/frame, zero fallbacks, verified panel wake or watts before real evidence.
