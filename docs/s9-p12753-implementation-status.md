# P12.7.5.3 — independent guard and battery budget audit

Opt-in boot argument `p12753=1` requires the existing P12752/P12751/P1275/P1274/P1273 chain. Absence leaves the previous firmware policy unchanged. No new physical CPU idle state, voltage, bus SET, panel sleep, DCS or UFS register operation.

## Guard

Existing CPU governor worker calls p12753_guard_tick at most 5 Hz, independent of P1274 profile ownership. Direct BIG/LITTLE TMU, cached GPU temperature age, battery temperature; lower-only ceilings compose with existing stock/thermal/experimental limits. OFF mild BIG1261/LITTLE1248 MHz, including a 5 s wake tail; OFF rising/load or hot/invalid sensors BIG1066/LITTLE1053 MHz. Severe triggers include BIG>=70C, LITTLE>=68C, GPU>=70C, battery>=45C, invalid/stale input, OFF sum load>=150, BIG>=65C or LITTLE>=64C while OFF, and selected fast rising conditions. Recovery needs 5 s at BIG<=63C, LITTLE<=62C, GPU<=65C, battery<44C. Requested OPP must exist; LITTLE cannot undercut existing stock/storage floor. It may limit startup until sensors become valid. No claim that the observed 86C burst will remain <=74C until hardware tested.

Read kern.hakios.p12753_guard for live/peak/changes/sensor mask. Guard remains active outside tests. P1274/REC retain their own cap/qualification and all cores remain online.

## Audit

p12753_arm (root, explicit boot opt-in) selects one phase:
1 STOCK120, 2 BASE15, 3 PSR, 4 LITTLE949, 5 ABOX, 6 BT, 7 WIFI, 8 TICKER, 9 BUS, 10 STOCK60. 0 requests cancellation. No automatic module progression. New stock phases set no P126/P127 policy; baseline still includes the P12753 safety guard. FG and WFI producers use an independent observe gate but require the existing P125 lease. BASE15 uses P127=1; all extra modules compare to BASE15, not stock. Module admission is the original P127 arm helper. Existing same-boot functional gate required where defined. PSR requires prior successful same-boot mask/unmask plus host-reviewed connected ABA report. No combined or lower-than-949 offline policy is added here.

Arm while cool, plugged and idle. WAIT state bounded 90 s from arm, with no experiment policy. Observe a new USB-down event and fresh FG external=0 after down; display OFF, G3D PMU OFF, safe UFS, valid direct TMU and quiet load/input for at least 20 s before starting. Transition wake may occur before the quiet window; after start, wake, link/FG change, GPU ON, excessive load, invalid/thermal data, conflict, cancellation or expired qualification ends the audit. Read-only STOCK120/BUS last 120 s; other phases 60 s. Policy leases are clipped, never extended, and legacy hard guards remain. Start and end are kernel timestamps, independent of USB transitions and host wait. Completion reason10, no rearm. Freeze retains first stop sensor values and mask. Mask bits BIG=1, LITTLE=2, GPU=4, BAT=8, invalid/stale=16, display=32, link=64, GPU domain=128, load=256, conflict=512, timeout=1024, cancel=2048.

96 bounded RAM rows, thermal/sample cadence 2 s, direct guard cadence 200 ms maximum. BUS only: 13 ACPM GET attempts rotating MIF/INT/CPUCL0/CPUCL1/G3D/INTCAM/FSYS0/CAM/DISP/AUD/IVA/SCORE/CP every >=4 s. Store raw response, errno, timestamp, latency, exact matching FVMAP OPP voltage if available; voltage is table metadata, NOT measured rail. Correct the old P12752 mode2 baseline driver-mask gate (BASE implies 15). Read existing external PMU status for G3D/DPU/ISPPRE/MFC/AUD via bounded map, unsupported mapping/offset -> UINT32_MAX. DECON frame counter only when DPU PMU status confirms ON. No DSI transfer/rail proof; no claim all domains audited by PMU. BUS diagnostic includes observer cost; exclude from power ABA.

Host uses existing serial disconnect/reconnect recovery, checkpoint before unplug, same-boot nonce + arm + phase verification, frozen cursor readback and incremental CSV. Audit53Power rejects interrupted or partial windows, unknown GPU, wrong policy/driver, FG gaps/nonnegative current/external input, <80% covered FG/thermal span, restore mismatches. Integrates signed FG current*voltage by trapezoid, only covered interval. Driver counters include setup/restore; not exclusive attribution. Audit53Compare requires same boot, chronological equal windows, comparable start temperatures and mean voltage, baseline drift <=10%, applied/restored/verified non-BUS. Marginal delta is not isolated rail power and cannot be summed blindly.

## Scope deliberately not expanded

Deep LITTLE 832/715/598/455 and REC2/1/0 are retained through the existing qualified connected/burst tests, not added to the new offline audit. INT/DISP/MIF/INTCAM/CAM SET and rail writes are withheld: no pre-use restore/dependency proof. No new DCS, physical CPU_OFF/SUSPEND/CPD/SICD, or combined offline qualification. No profiler rewrite. The 2.183 W historical observation remains an approximate battery-only baseline, not a verified new stock audit. Real S9 compilation, boot, wake, storage, functional and energy measurements are required before hardware qualification.
