# P1278 (Rev8) S9 connected display recovery and foreground pilots

## Scope
Rev7 demonstrated same-boot automatic LITTLE 598 MHz and ABOX qualification, lease release on wake and stock restore. A real S9 showed a stationary black region at the left corner and a gray flash at wake from panel sleep; UI motion otherwise normal, reboot cleared the corruption. The observed 0.37 A USB input compared with usual 0.41–0.49 A is an unisolated input-current observation, not battery power proof.

## Runtime
p1277=1 and p1278=1 grant permission only; no panel sleep, active CPU, IRQ, DVS or G2 enabled at boot. P12754 ABI6 and P1277 revision7 unchanged, p1278_revision=8.
- Mode 1: DCS28/29 only; shallow control.
- Mode 2: requires same-boot operator review of clean mode1 wake. DCS28/10, replay compression short packet type 07 and long PPS type 0a before DCS11, restore Samsung WQHD scaler/CASET/PASET/area/TE, existing brightness path. No power/voltage/oscillator/full reset sequence.
- Capture pre-off/after-wake host DSC, DPU geometry, error flags, link configuration. Fail closed on unknown variant, format or geometry. Read 0A/0E once per mode, bounded, diagnostic only.
- Serialize short trigger hold; verify transfer idle before packet writes and restore owned mask. Require generation-bound full-window latch, shadow taken, idle active DMA/DPP and new masked DSIM FRAME_DONE plus another frame counter; recheck under hold before DCS29. 120ms conservative minimum after 11; native and device timing unverified. No claim of GRAM CRC/content identity. 650ms timeout permits compatibility visible wake but retires pilot, never counts PASS. Uncertain wake requires recovery; no forced asleep disarm. A visual N retires the panel policy.
- Auto Idle retains the existing guard (<67/66/68C, battery <45C, fresh samples, UFS and exact lease restore). Foreground pilots use actual IRQ delivery and monotonic wait/spin/sleep/fallback statistics, G2 verified per-context request and existing active CPU boost limits. G2 request is not proof of saved bindings. No 800mV, no new DVS enable, no MIF/INT/PSCI writes.
- Rev8Suite keeps Auto Idle between tests, cools OFF before wake, requires actual visual Y, runs shallow then deep and short baseline/IRQ/G2/CPU/combined separately. Checkpoint can skip completed modules only on same boot with clean baseline and panel review bits. On new boot automatic qualification is necessary. Default cleanup restores owned controls; -KeepAutoIdle explicit success-only retention. No automatic takeover of prior dirty state. USB stays connected; not an energy trial.

## Verification boundary
Host C tests for geometry/refusal and actual Rev7 idle header mock; source contract checks and PowerShell parser/no-I/O preview. Exact PPS table verified against pinned reference locally. Native XNU/userland/EFI compile and physical panel wake, current/power and CPU rendering impact remain unverified. Require matching installer and host manifest and successful CI before attempting hardware pilot. Do not flash Rev7 kit as Rev8. Stop if thermal or rollback uncertain.
