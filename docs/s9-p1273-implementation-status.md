# P12.7.3 implementation checkpoint (not release-ready)

Base: P12.7.2, kernel branch s9/p12-4-guarded-thermal.
No CPU_OFF, CPU_SUSPEND/PSCI changes, voltage writes or new default hardware policy.
No native kernel/userland build or device verification has been performed for this checkpoint.

## Source delivered

- CPU recount recorder: opt-in boot arg `p1273=1`, explicit `kern.hakios.p1273_trace_mode=1`. OFF-only, stock-policy guard, 180 s maximum recording, first governor window with either cluster load >=60% triggers <=10 s postcapture, thermal/display guard or stop freezes capture. Eight per-CPU RAM rings, 128 x 250 ms bins (32 s history), 16 PID/task-uniqueid/TID owner slots per bin. Existing recount accounting supplies user/system ticks, idle/kernel/user kind, fragment and switch counts. Drop/clipped ticks and hook overhead are reported; never treat dropped data as zero CPU. Data may omit intervals not yet accounted when freezing; final partial bucket is not a precise instantaneous sample. The CPU hook introduces instrumentation overhead only while armed; no new high-rate polling thread. See stage 2 for GPU and governor records.
- Host `ThermalTrace` capture and separate `ThermalTraceDump` readout; frozen generation checked, masks/page counts validated, raw pages saved incrementally. Host refuses overwriting previous capture; reboot clears RAM. Do not reflash or reboot before dumping data. No trigger means inconclusive. Dump writes a bounded selector only, not a hardware policy.
- Metal logging: process-local environment `HAKIOS_METAL_LOG_AB=0` (existing log path) or `1` (rate-limit before formatting); fresh process per phase. Only two unsupported-layout selectors, nil return preserved. PID/TID, monotonic ticks, counts and logging elapsed time; the summary itself is not included in measured logging elapsed time. No global runtime A/B/A control yet; stage 2 adds descriptor and plan telemetry.
- Texture layout: real descriptor dimensions, block-edge checks, linear pitch required, checked region/linear stride arithmetic. Portable C test expanded. Actual GPU layout/readback, render hash, and no-copy lifetime tests remain outstanding.
- LITTLE floor: `p1273_floor` stores last arm denial; separate live guard. Bits 0 target, 1 policy/enable, 2 other CPU mode, 3 online counts, 4 exit mask/recommended cores, 5 floor or DT min, 6 UFS safe, 7 UFS busy, 8 no input observed, 9 fingers, 10 input quiet, 11 load, 12 thermal ceiling, 13 OPP unavailable. `arm_thermal` carries independent thermal/display guard. The original guard is not relaxed. Existing lower OPP trials remain individually gated.
- ACPM: eight read-only cached domain records `p1273_bus0..7`, domain IDs 0,1,5,7,8,9,2,3 respectively. Round-robin one query per 10 s while existing observation and P127 policy are active. Signed errno, successful raw rate word (not entire firmware message), sampled/valid/zero, timestamp, age and latency. Unsampled/stale/failed/zero are distinct. No writes. `BusTrace` uses 90 s existing baseline lease; no claim of domain support until device evidence.
- WFI: `p1273_wfi0..7` version 2 exposes 9 count/tick pairs with boundaries 100us, 500us, 1ms, 2ms, 3.5ms, 10ms, 20ms, 50ms. Legacy v1 merges final three bins into >=10ms. Host `-P1273Telemetry` enables v2. `P1273Diagnostics` reads cached floor/bus and cumulative WFI evidence without arming policy.

## Stage 2 source integration (not release-ready)

- CPU/GPU: the trace now freezes immediately on display-on and cannot be overwritten until reboot. GPU jobs capture the submitting thread's PID/task unique ID/TID and existing client owner tag at enqueue (not the worker identity). The 1024 completed-job ring, first successful wake record, enqueue/start/end/ensure-on timestamps and coverage counters are read through frozen selectors, with no new GPU register reads. Pending, overwritten and pre-arm jobs are not attributed. The GPU worker interval is not pure hardware execution time. A successful GPU wake can trigger capture. The governor caches load, rate, thermal index and temperatures with TMU age on the same monotonic clock, one sample per 250 ms bin. Rates marked asked are not actual readback. Use ThermalTraceDump and ThermalGpuDump before reboot.
- Metal: bounded format/descriptor histogram and first-format logging, plus process-local HAKIOS_METAL_LAYOUT_PLAN=1 dry run using the layout planner and pitch query. Unsupported selectors still return nil when layout is disabled. No process-global or PosterBoard enablement.
- OFF burst cap: p1273_cap_mode=3 observe, 1 mild (BIG 1469/LITTLE 1248 MHz), 2 stronger (1261/1053 MHz), 0 cancel. Explicit opt-in and prior frozen triggered trace required. Wait at most 60 s for sustained >=60% load (250 ms); active lease at most 15 s, lower-only min with normal ceiling, guard for display, thermal, input, topology, UFS and other experiments. Stronger requires completed mild trial with both readback hits and no asked-only flag, plus host explicit approval. OffBurstCapABA defaults to observe/mild/observe; no trigger is inconclusive. This does not establish workload matching or energy benefit.
- PSR: one spinlock/owner for TE mask, release and final shadow request; never claim foreign mask. Legacy timer drains for B; B uses effective legacy threshold, A1 rearms legacy timer. p1273_psr exposes owner, threshold, drain, ticks, masks, unmasks and faults. EnergyTrials -P1273Telemetry checks matched 300 ms baseline and A/B/A evidence. Native frame/wake behavior and lock ordering remain unqualified.
- OfflineABA: explicit -AllowOfflineTrial and one OfflineModule (ABOX, BT, WIFI, TICKER or LITTLE949). All three A0/B/A1 unplugged, fixed 60 s kernel deadline independent of USB reconnection, early reconnect/revoke invalid, host waits 65 s and checks planned reason 10 on both leases. Config reset and restoration checked. Gauge samples must be discharging, external=0, plausible voltage, consecutive with gaps <=15 s; trim 5..55 s, integrate trapezoidally on common observed support >=30 s. No extrapolation. Report net battery W, not rail power or causal savings. A/B/A boot continuity uses anchor/Hz/monotonic timestamps/counters, not a unique boot nonce. Legacy EnergyOffline remains a connected/unplug/reconnected protocol.
- Installer: optional exact p1273=1, rejects duplicate/other values and metal_layout=1 in diagnostic baseline; checks paired source, runs P1273 source contract and portable C layout test. No new boot arg enabled by default. Kernel and installer changes are uncommitted.

## Stage 3 source integration (not release-ready)

- FunctionalGate: exact whitelist 3 USB, 5 ABOX, 257 BT, 129 WiFi, 513 ticker, 17 LITTLE949, 903 COMBINED5, 919 COMBINED6. Kernel evidence is bound to a prepared generation, exact OFF lease, stopped lease identity and post-restore review. Pending review expires at 300s, gate trial lease at most 120s; qualifications live in RAM at most one hour and never survive reboot. Fault/fallback counters invalidate qualifications and prerequisite expiry invalidates dependent profiles. Host requires explicit -AllowFunctionalGate and interactive Y only after real foreground function tests; no timeout ACK. Missing driver evidence refuses ACK. USB requires physical link cycle and quiet path; audio requires stop/resume parity, actual sink frames, capture frames and moving RDMA after restore; BT and WiFi require active and post RX/TX, IRQ/restore evidence; ticker requires wait/due/wake/cancel. Counters demonstrate exercise, not sound quality or over-air delivery; operator verification remains required. LITTLE949 requires actual measured floor and stock restoration plus display-on revoke reason4. No synthetic evidence injection.
- COMBINED5 requires all five individual gates (31), COMBINED6 additionally requires floor and qualified COMBINED5 (127). First combined functional trial requires exact prepared gate; subsequent connected/offline measurements require own gate bit too (95/255). Host -AllowCombined, kernel p1273=1 and real same-boot qualification required. CombinedConnected A/B/A <=30s each, OfflineABA combined B remains fixed 60s. Report per-module path evidence and no full-profile causal claim if a path has no evidence. USB quiet N/A unplugged; floor requested path is not measured proof in each energy window. All normal restore, thermal and topology guards remain. No PSR in 903/919.
- CPU measured rate: FREQ_GET=0 may force asked-only cache; use existing governor measure_mhz instead. Floor gate compares actual and requested within +/-3%, with measured stock restoration. Mild cap completion now requires at least two matched independent both-cluster samples and no bad samples, actual rates no higher than targets within measurement tolerance; asked flags remain diagnostic. No extra measurement timer.
- OfflineABA now uses random boot-local nonzero nonce, checked after each phase, plus existing anchor/Hz/monotonic ordering. No persistent ID. Battery discharge observation still needs matched workload, temperature and SoC for causal comparisons.
- Metal explicit isolated `/redwood/bin/metal_test p1273-metal-log-aba`: 64 calls per selector per process, 0/1/0 logging with layout disabled, 128 nil results, PID/elapsed/status, per-child 30s timeout. `p1273-layout-check` runs separate opt-in process: RGBA8 16x16 real pitch, CPU round trip, invalid bounds nonmutation, reject private/mip/backed descriptors, GPU blit exact bytes and shader-render exact bytes/hash, deallocator once and correct pointer/length. No launchd/PosterBoard change. Compressed upload checks actual runtime return and packed block image size (still a copy); linear import only transfers deallocator ownership after successful texture construction. No claim of compressed zero-copy or native test success.
- cputop duplicate 10s worker removed; existing 5s summary reports monotonic timestamp, enumeration overhead and truncation. No extra worker.
- Paired installer preflight requires new gate header and tests, portable gate C test and layout C test; kernel CI also includes Windows gate mock and iOS SDK syntax check for metal_test.m.

## Remaining release blockers

Native XNU/kernel and userland/Metal build, full paired installer CI, real S9 functional gates and connected/offline energy tests, actual OPP/ACPM support, thermal recorder coverage/overhead and PSR frame/wake/lock review still outstanding. Real workload for ticker cancellation and WiFi/BT traffic may be unavailable; missing evidence means no qualification. No measured energy improvement asserted. Longer than 60s offline remains disabled. No firmware build, flash, commit or push. Do not release from source/mock tests alone.
